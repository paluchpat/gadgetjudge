# GadgetJudge

The portfolio site for GadgetJudge's independently made Android apps.

## Local development

Install dependencies once with `npm install`, then start the hot-reloading local site with:

```sh
npm run dev
```

Open the local address shown in the terminal. Changes to the page and styles appear automatically.

To add another app, add its feature image to `public/images` and add one entry to the `apps` list in `app/page.tsx`.
